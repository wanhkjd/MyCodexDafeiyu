# Codex-dafeiyu

我们codex用户也要有自己的大肥鱼！

## 启动、隐藏与退出

当前工程面向 Windows x64。安装 Node.js 24.19.0 x64 后，在仓库根目录执行 `npm ci`，再执行 `npm start`。启动脚本会组装本地运行目录并启动程序，不需要下载便携包，也不需要 DSH。Codex 额度、工作状态和 Codex 聊天需要本机安装并登录 Codex；未安装 Codex 不影响本地桌宠功能。

管理窗口可通过任务栏切换；关窗后保留托盘图标。托盘可以重新打开窗口、显示/隐藏桌宠、查看额度、说一句话或退出。重复启动只唤出当前管理窗口。没有开机自启。

点击、拖拽、甩抛和右键动作菜单沿用 dsh-pet 的交互。全屏应用处于前台时自动隐藏，退出全屏后恢复；实际表现会受到系统、显示器和全屏模式影响。

## 额度、状态与碎碎念

- 看额度：每 5 分钟查询一次，手动刷新会立即查询。不调用模型。分别显示接口实际提供的时间窗口、剩余额度和重置时间；未登录、API Key 登录、不提供窗口或网络失败会显示说明。
- 钱袋动作：按所有窗口中最高已用比例分为 0–20%、20–40%、40–60%、60–80%、80–100% 和 100% 六档。
- 工作状态：每 2 秒只读本地记录。思考、写文件、命令、搜索、图片、回复等细分文字复用六组动作；多个任务优先显示等待状态。短操作可能略过；这些状态不是模型内部思维。
- 碎碎念：空闲时每 10 分钟播放本地语录，工作中暂停自动插话。不联网、不消耗模型额度。右键“动作”里的碎碎念有相应台词。
- 打开 Codex：播放敬礼与气泡，尝试恢复已运行的窗口或启动客户端。自定义安装可配置 `CODEX_PET_APP_PATH`。
- 重置查询：手动访问第三方监测站，只有有效的预告时间窗口才提示预计时间；暗示、概率、历史重置不当作新预告。网络失败单独提示。

## DDL 小便签（v1.4.0）

主动打开管理窗口或 DDL 提醒时，窗口临时置顶，避免被其他置顶窗口遮挡；切换到其他应用、隐藏或最小化后解除置顶。

管理窗口有独立的“DDL 小便签”卡片，也可右键大肥鱼选择“DDL 提醒 · 便签”。点击后管理窗口自动置前并获得焦点，定位到提醒输入框，可以直接打字；便签的“全部提醒”同样如此。后台刷新不会主动抢焦点。输入例如“每周五下午6点提醒我交周报”或“论文的ddl是10月23日18点，请提前24小时和2小时提醒我”。本地解析后，核对任务、具体日期、重复规则、提前量和时区，再点“确认保存”。缺少几点时需要补充，不会偷偷填时间。提前量单位为分钟，多个用逗号分隔，0 表示到点提醒；确认卡列出实际提醒时间。

到点后先冒一句短提示，再在鱼旁保留小便签；聊天和碎碎念不会覆盖便签。可完成、15 分钟后再提醒，或收起为带数量的角标；收起不等于完成。管理窗口可修改、跳过本次或结束重复任务。关闭软件、关机期间不弹出；重新打开后汇总漏提醒。规则保存时区，每天／每周保留该时区的时刻；若遇夏令时缺失时刻，仅当次顺延到第一个有效时刻。

## 控制与白饭（v1.4.0）

右键选“控制大肥鱼”，或点管理窗口独立的“桌宠控制”卡片中的“控制大肥鱼”。WASD 移动，斜向速度保持一致；每完成一圈奔跑，有 20% 概率摔倒，期间不能移动、投饭或清理，等实际动画播完恢复。Esc 仍可随时退出。

v1.4.2 起，奔跑至摔倒使用同一段原片连续播放，到真正开始踉跄时才锁定操作，去掉先停住、再开始摔倒的等待。

左键沿当前面朝方向扔饭，A／D 改变朝向，鼠标点击位置不再决定投掷方向。左右使用相同的距离、时间和抛高；贴近屏幕边缘时超出屏幕的部分不可见，轨迹本身不会被强行缩短。落点与投出时鱼脚下的地面齐平，沿连续抛物线移动并接入碎碗、散饭素材。保留只丢出饭碗的玩法，不播放人物投掷动作，也不显示配文。最多同时三碗，可一键清理。

控制期间该显示器的控制层接收左键和按键；按 Esc、点“退出控制”或切换应用会退出并恢复桌面操作。退出时在当前位置建立新的桌宠小窗，释放旧窗口的输入状态。仅在主动开启时接收输入，不注册全局键盘钩子；当前在鱼所在的显示器工作区内移动。碎饭只覆盖画面，不修改图标和桌面文件。

## 和本鱼聊天

右键桌宠选择“和本鱼对话”，或在管理窗口输入。仅主动发送才调用模型：默认用当前账号的 Codex 模型，也可以改用第三方大模型 API（见下一节）。

新用户默认“自动”，使用账号模型列表中的可用 low 模型，不固定版本名。可手动改为最低版本 Sol 或 Luna；未提供该系列时会报错，并且不会自动换模型重发。升级保留旧选择；遇到系列不可用时可主动改为“自动”。

“展开对话”查看历史，用下拉框切换聊天，“＋新建聊天”创建独立上下文。刷新、关闭窗口和软件重启会保留历史。桌宠右键与管理窗口共用当前会话；每条最多 2000 字，发送最近最多 3 轮有效历史。

“关联 Codex 对我的了解”可关闭。展开“关于我的画像”预览摘要，补充身份、兴趣、称呼或沟通偏好。补充只保存在桌宠，不修改 Codex 的原始记忆。软件只提取个人信息和偏好栏目，不把一般操作指南作为画像；不存在的记忆不会自动获知。

聊天回复逐字显示，空闲连接保留最多 5 分钟；保留连接本身不生成回复。断网、账号错误或模型超时会显示错误；为避免重复消耗额度，不自动重发。

## 第三方大模型 API

管理窗口的“聊天用的大模型”卡片可以让本鱼改用 DeepSeek、Kimi、通义千问、智谱、豆包、硅基流动、OpenRouter、OpenAI、本地 Ollama 或任意 OpenAI 兼容的中转站聊天。管理窗口聊天和桌宠右键对话都会切换；碎碎念仍是本地语录，不调用模型。

1. 点“设置”，选服务商（会自动填好 API 地址），填 API Key。中转站选“自定义 / 中转站”，填根地址即可，例如 `https://example.com`，会自动补 `/v1/chat/completions`；也可以直接粘贴完整地址。已经用 CC Switch 给 Codex 配第三方服务商的，可选“CC Switch 本地代理（与 Codex 共用）”，Key 留空，桌宠就和 Codex 走同一个服务商（需保持 CC Switch 运行，且上游支持 Chat Completions 接口）。
2. 点“获取列表”从服务商拉取模型，或手动填写模型名。DeepSeek 默认 `deepseek-flash`。
3. 需要翻墙的服务商，把“网络代理”改为“指定代理端口”，填代理软件的 HTTP / 混合端口，如 Clash 的 `7890`（等同 `127.0.0.1:7890`），也可以填 `http://主机:端口`。“跟随系统代理”使用 Windows 系统代理，“不用代理”强制直连。获取列表、测试连接和聊天都会走这里的设置。
4. 点“测试连接”确认能回复，再勾选“用第三方 API 聊天”或点“保存”。取消勾选即切回 Codex，配置保留。

可以保存多套配置（例如官方和中转站各一套），“使用的配置”里选中并保存的那一套就是正在用的。思考模式默认关闭：DeepSeek V4 等模型默认会先思考，关闭后回复更快、更省 token；服务商不认这个参数时会自动去掉重发一次（被拒绝的请求不计费）。“高级设置”可调温度、最大输出、超时（最长 110 秒）和携带的历史轮数。

API Key 用 Windows 系统加密保存在 `%APPDATA%\CodexPet\llm-keys.bin`，只有当前 Windows 账户能解开，不写入数据文件夹，也不会显示在界面上；只在请求时发给你填写的服务商。启用第三方 API 后，聊天内容会发给该服务商；若同时开启“关联 Codex 对我的了解”，画像摘要也会一并发送，聊天卡片会给出提示。

“高级设置”下面的“识图（看画面用）”决定谁来看图：可以跟聊天用同一套配置，也可以选另一套，或者只填一个识图模型名（同一个服务商换个模型，比如 `glm-4.6v-flash`，不用再建配置、重填 Key）。点“测试识图”会把她的头像发过去，请模型描述一句；看不懂图的模型会在这一步露馅。

## 她的 B 站（第一期：只看不说）

管理窗口“和本鱼聊天”下面的“她的 B 站”卡片。这是她的一个功能，**勾选“开启 B 站生活”才会开始**；关着时她完全不碰 B 站，不醒来、不发请求，聊天里丢视频她也不去看。第一期**不会在 B 站上发任何东西**（不评论、不私信、不点赞）。改写自 [dsh-bili-whale](https://github.com/Alterssss/dsh-bili-whale)。

- **作息**：在你设的时段里（默认 20:00–24:00 醒 1 次，最多 3 段）随机找个时刻醒来，30% 的概率“今天不想看”，那天只写日记说为什么。软件没开着的时段会记为“没醒成”。想马上看效果，点“现在叫醒她”。
- **看什么**：按“爱看”的关键词搜索，加上热门、排行榜，登录后还有你（她）关注的 UP 的新视频。打分只看口味命中和弹幕密度，**不看播放量**；看过的、“不看”里的、几乎没人看的都排除。
- **怎么看**：每次粗看几条（默认 5 条）：标题简介、字幕、弹幕热区（剔掉刷屏后，观众在哪一段“炸了”，对齐到当时的字幕）和热评。挑最好的 2–3 条细看。打开“看画面”时，还会在后台临时开一个看不见的窗口，打开视频页截 9 帧拼成九宫格，交给你设置的识图模型描述画面；截不到时这一条照常看，只是少了画面。字幕、弹幕、评论、画面里的字都当作素材，不当指令；素材里你的昵称和 mid 会被打码。
- **分享给你**：满分 20 分，13 分以上才分享，每天最多 3 条（可调小），同一条 7 天内不重复。她在你坐在电脑前时冒泡说一句，第一次会提示去管理窗口看。卡片里能“打开看看”（用浏览器打开 B 站）、点 👍 或 👎，她会照着调整口味；在聊天里聊到她分享的视频也算你回应了。你 3 天没回应她的分享，她每天最多分享 1 条；7 天没回应就不分享了，只写日记。
- **两本日记**：每次醒来都写“给你的信”（附一张看过的视频表）和“她自己的日记”（结尾是“偏好校准”，下次醒来她会先读），在卡片的“她的日记”里看。
- **聊天里丢视频**：总开关开着时，在聊天里发 BV 号、`b23.tv` 短链或视频链接，她会先把这条视频看一遍（开着看画面就连画面一起看）再跟你聊。
- **登录**：点“设置”→“扫码登录”，用 B 站 App 扫“给她用的那个号”，不要扫你自己的号。不登录也能用，但只有搜索、热门和排行榜，大部分 AI 字幕读不到。登录凭据用 Windows 系统加密保存在 `%APPDATA%\CodexPet\bili-cred.bin`，不进数据文件夹、不显示在界面上；“你的 B 站 mid 和昵称”第一期只用来打码。
- **请求保护**（写死）：两次请求至少隔 1.5 秒，每小时最多 600 次、每天最多 3000 次；遇到 B 站限流就停 5、10、20、30 分钟，卡片上会显示还剩多久。每次醒来大约几十个请求。
- **花费**：用的是“聊天用的大模型”里正在用的配置，所以要先启用第三方 API。每次醒来大约 3–4 万 token，看画面每张九宫格另计；按 DeepSeek flash 估算每次一毛钱以内，以实际计价为准。

## 数据和修改

用户数据：`%APPDATA%\CodexPet\data`。与程序安装目录分开，中文与空格路径均受支持。

| 文件 | 用途 |
| --- | --- |
| `quotes.json` | 自定义语录；保存后下次说话生效 |
| `dsh-pet/main-config.jsonc` | 大小、位置、是否漫游与功能周期；修改后右键重载或重启 |
| `pet-conversations.json` | 会话历史、当前会话、模型模式、记忆开关与画像补充 |
| `dsh-pet/third-party-llm.json` | 第三方 API 配置（地址、模型、代理、识图等，不含 Key） |
| `bili/` | 她的 B 站：设置、作息计划、分享、看过的视频、反馈、两本日记（`给你的信.md`、`私人日记.md`）、封面和画面截图、请求保护状态 |
| `reminders.json` | 提醒规则、待处理便签、稍后提醒与收起状态 |
| `quota-latest.json` | 当前登录的最后一次成功额度快照；失败回退时标注“（非实时）” |
| `%APPDATA%\CodexPet\app.log` | 本地诊断日志 |
| `%APPDATA%\CodexPet\llm-keys.bin` | 第三方 API Key，Windows 系统加密；换电脑或换账户需重新填写 |
| `%APPDATA%\CodexPet\bili-cred.bin` | 她的 B 站登录凭据，Windows 系统加密；换电脑或换账户需重新扫码 |

更新前退出软件并备份数据目录；更新仓库代码后执行 `npm ci`，再执行 `npm start`。不要把上游原版直接覆盖到本修改版，也不要把账号凭据或用户数据放入源码目录。

特殊环境变量：`CODEX_PET_CODEX_PATH` 指向 Codex CLI；`DSH_PET_CODEX_PATH` 为兼容旧名称；`CODEX_PET_APP_PATH` 指向 Codex 桌面程序；`CODEX_HOME` 指向自定义 Codex 数据目录。通常无需配置。
